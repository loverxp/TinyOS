## 二、详细分析

### 2.1 用户态 libc 扩展

**新增文件:**
- `user/libc/errno.c` — 全局 `errno` 变量定义
- `user/libc/termios.c` — POSIX 终端 I/O 兼容层（全部为 stub）
- `user/include/errno.h` — 25+ 标准错误码定义（EPERM, ENOENT, EINVAL, ETIMEDOUT 等）
- `user/include/termios.h` — 完整的 `struct termios` 类型定义 + 标志常量 + 波特率常量
- `user/include/unistd.h` — POSIX 风格系统调用封装
- `user/include/fcntl.h` — 文件控制标志 + VFS 数据结构 + `open()`/`mkdir()`/`rmdir()`/`fstat()` 封装

**意义**: 这些扩展为后续移植第三方用户空间程序（如简单的 Unix 工具）提供了 POSIX 兼容基础。termios 为全 stub 实现（`tcgetattr` 始终返回 raw mode，`tcsetattr` 静默接受），足以让检查 termios 的程序编译通过。

### 2.2 规划中的 VFS 系统调用（仅头文件）

`user/include/unistd.h` 和 `user/include/fcntl.h` 中声明了以下系统调用封装，但 **内核中断处理程序 (`drivers/interrupts.c`) 中尚未实现对应的 case 分支**：

| Syscall # | 函数 | 用途 |
|-----------|------|------|
| 28 | `open(path, flags)` | 打开文件，返回文件描述符 |
| 29 | `read(fd, buf, size)` | 从文件描述符读取 |
| 30 | `write(fd, buf, size)` | 向文件描述符写入 |
| 31 | `close(fd)` | 关闭文件描述符 |
| 36 | `mkdir(path)` | 创建目录 |
| 37 | `rmdir(path)` | 删除目录 |
| 38 | `unlink(path)` | 删除文件 |
| 56 | `getpid()` | 获取当前进程 ID |
| 59 | `sbrk(increment)` | 扩展/收缩程序堆 |
| 60 | `lseek(fd, offset, whence)` | 重定位文件读写位置 |
| 61 | `fstat(fd, buf)` | 获取文件状态信息 |

**VFS 数据结构**（`fcntl.h` 中已定义）：
```c
typedef struct {
    uint32_t size;
    uint8_t  type;
    uint16_t year, month, day;
    uint16_t hour, minute;
} vfs_stat_t;

typedef struct {
    char     name[14];
    uint8_t  type;
    uint32_t size;
} vfs_dirent_t;
```

**分析**: 这表明 v4.0 分支正在规划从 FAT16 直接操作向 VFS 虚拟文件系统层 + 文件描述符抽象的过渡。头文件已就绪，内核实现待补充。

### 2.3 HTTP 客户端

**文件**: `kernel/httpclient.c`, `include/httpclient.h`

**功能**:
- 发送 HTTP/1.0 GET 请求，包含 `Host:` 和 `Connection: close` 头
- 支持 DNS 域名解析（自动区分域名和 IP 地址）
- TCP 连接带超时（3 秒连接，5 秒响应）
- 4096 字节响应缓冲区
- 基于回调的 TCP 数据接收累积

**Shell 命令**: `http-get <host> [port] [path]`
- 默认端口 80，默认路径 `/`
- 支持外部站点（如 `httpbin.org`）和宿主机本地服务器

### 2.4 TCP 客户端连接

**新增 API** (`kernel/net.c`):
- `net_tcp_connect(ip, port)` — 发起 TCP 三次握手，带 SYN 重试和 ARP 轮询
- `net_tcp_is_connected()` — 检查连接状态
- 临时端口分配器（ephemeral port），用于客户端出站连接

**分析**: 此前 TCP 仅支持服务端监听（LISTEN/SYN_RCVD），v4.0 新增了客户端主动连接能力，是 HTTP 客户端的基础。

### 2.5 DNS 解析增强

**CNAME 链处理**: DNS 响应中可能返回 CNAME 记录指向另一个域名，最终才是 A 记录。v4.0 的 DNS 解析器遍历所有应答记录，正确处理 CNAME→A 链。

### 2.6 Shell 管道 (Pipeline)

**实现**: `kernel/shell.c` 中的 `handle_pipeline()` 函数

**工作原理**:
1. 解析 `|` 分隔符，拆分为最多 8 个命令段
2. 为每对相邻命令创建 Pipe（IPC 管道）
3. 第一段：stdout 重定向到 pipes[0]（通过 `printf_pipe_redirect` 钩子）
4. 中间段：stdin 来自 pipes[i-1]，stdout 重定向到 pipes[i]
5. 最后一段：stdin 来自 pipes[num_pipes-1]，stdout 正常输出
6. 每段执行后调用 `pipe_shutdown_write()` 发送 EOF 信号

**关键机制**:
- `printf_pipe_redirect` — 全局函数指针钩子，`printf` 输出可被重定向到 pipe
- `scheduler_set_stdin_pipe()` — 设置当前任务的 stdin pipe，syscall 21/22 自动从 pipe 读取
- `pipe_shutdown_write()` — 半关闭机制，写端关闭后读端收到 EOF
- `pipeline_depth` 防递归保护

**`write` 命令的管道支持**: 当 `write <file>` 未指定文本参数时，从 `stdin_pipe` 读取内容，支持 `echo hello | write file.txt` 模式。

### 2.7 fork/exec 系统调用

**Syscall 25 (fork)**:
- 克隆当前任务的内核栈和用户栈（独立副本）
- 父进程返回子进程 PID，子进程返回 0
- 子进程 `is_forked` 标志设为 1
- 子进程退出时走 `forked_task_exit_handler` 路径（调用 `task_exit()`）

**Syscall 26 (exec)**:
- 替换当前进程的 EIP 和用户 ESP
- 清零所有通用寄存器
- 设置 EFLAGS (IF=1, IOPL=3)

**forktest 用户程序** (`user/apps/forktest.c`):
- 验证 fork 返回值（父/子进程区分）
- 测试 yield 交替执行
- 测试 task_exit 正常退出

### 2.8 Shell 增强

**命令历史** (`HISTORY_SIZE=16`):
- 循环缓冲区存储，Up/Down 箭头浏览
- 重复命令抑制（连续相同命令不重复记录）
- 浏览历史时保存当前输入，返回后恢复

**Tab 自动补全**:
- 37 个内建命令注册表
- 单匹配：自动补全并追加空格
- 多匹配：计算公共前缀补全 + 列出所有匹配项
- 仅补全第一个词（命令名）

**行编辑**:
- Home/End 光标移动
- 退格删除
- 屏幕重绘（`shell_redisplay`）

### 2.9 新增 Ring 3 用户程序

| 程序 | Syscall 使用 | 说明 |
|------|-------------|------|
| `uptime.elf` | syscall 27 type=0 | 系统运行时间（ticks → 秒.毫秒） |
| `date.elf` | syscall 27 type=1 | RTC 日期时间 |
| `rand.elf` | syscall 27 type=2 | xorshift32 随机数 |
| `meminfo.elf` | syscall 27 type=3 | 物理内存使用（总/空闲/已用/MB） |
| `diskinfo.elf` | syscall 27 type=4 | FAT16 磁盘信息 |
| `forktest.elf` | syscall 25/26/8/0 | fork/exec/yield/exit 验证 |

所有程序通过 `run_embedded_elf()` 通用加载器执行，ELF 通过 `incbin` 嵌入内核二进制。

### 2.10 Syscall 27 (get_system_info) 统一查询接口

统一的系统信息查询 API，替代了此前各命令直接调用内核函数的方式：
```c
int get_system_info(uint32_t type, void* buf, uint32_t max_len);
```

5 种查询类型：uptime(0) / date(1) / rand(2) / meminfo(3) / diskinfo(4)。返回实际写入字节数，失败返回 0。

### 2.11 FAT16 子目录支持

**新增能力**:
- 完整路径解析（`DIR1/SUBDIR/FILE.TXT`）
- `mkdir` 命令：创建目录，自动生成 `.` 和 `..` 条目
- `rmdir` 命令：删除空目录（检查非空）
- `ls/cat/write/rm` 均支持路径参数
- 目录自动扩展（满时分配新 cluster）
- 多 FAT 副本写入
- RTC 时间戳写入文件创建/修改时间

### 2.12 crt0.s 改进

- `__libc_exit()` 函数：exit code 通过 `ebx` 寄存器传递给 syscall 0
- 内核侧读取 `arg1`（EBX）作为退出码
- 更规范的 C 运行时启动流程

### 2.13 Socket 抽象层

Berkeley 风格的 Socket API（`kernel/net.c`）：
- 最多 8 个 socket
- 支持 `SOCK_STREAM` (TCP) 和 `SOCK_DGRAM` (UDP)
- 1024 字节环形接收缓冲区
- 完整的 `sock_create` / `bind` / `connect` / `send` / `recv` / `listen` / `close`
- 超时接收（`sock_recv` with `timeout_ms`）
- UDP 按 `local_port` 自动路由到对应 socket
