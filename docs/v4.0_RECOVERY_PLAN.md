# TinyOS v4.0 功能验证与提交计划

## 背景

`recovery/v4.0` 分支已有基础 v4.0 功能（HTTP 客户端、fork/exec、Shell 管道、FAT16 子目录、syscall 27 等），
但 `backup/v4.0-untracked` 分支还有更多未提交的新文件需要迁移过来：

- **VFS 虚拟文件系统层** (vfs.c/vfs.h, DevFS: /dev/null, /dev/zero)
- **MBR 分区解析** (mbr.c/mbr.h)
- **信号系统** (signal.c/signal.h, SIGHUP/SIGINT/SIGKILL/SIGTERM)
- **16+ 新用户程序** (ls/cat/more/ping/arp/net/netstat/dhcp/pci/write/rm/mkdir/rmdir/dino/si/tinyhttpd/filetest/kill)
- **Shell 增强** (后台任务 `&`, `jobs`, `sh` 脚本执行)
- **Ctrl+C 中断支持** (SIGINT 投递)
- **调度器修复** (per-task kernel_exit_esp)
- **Python 测试框架** (tests/ 目录)
- **libc 扩展集成** (errno.c/termios.c 纳入构建)

## 原则

1. 每步从 backup 分支 checkout 相关文件
2. 做必要的内核集成修改（shell.c, interrupts.c, Makefile 等）
3. `make` 构建通过
4. 运行 QEMU 自动/手动测试
5. 更新相关文档 (AGENTS.md, ROADMAP.md, USAGE.md)
6. `git commit` 提交
