项目定位
从教学内核到完整操作系统
GUI 桌面 · 网络协议栈 · 多任务调度
涵盖引导、内存管理、中断处理、抢占式调度、用户态切换、 文件系统、VBE 高分辨率图形、窗口管理器与 TCP/IP 网络， 通过混合语言开发展示底层系统编程的真实世界实践。

特色功能
不只是内核，更是完整的操作系统

GUI 桌面环境

VBE 800×600 高分辨率，窗口管理器支持拖拽/关闭/Z-order，鼠标指针，`gui` 命令一键启动

HTTP WebServer

内核内置 TCP/IP 协议栈，端口 80 HTTP 服务器，宿主机 :8088 端口转发即可浏览器访问

抢占式多任务

Round-Robin 调度器，IRQ0 驱动时间片，schedtest 命令测试并发任务

网络协议栈

ARP / IPv4 / ICMP / UDP / TCP 全实现，ping / send 命令直接测试

FAT16 文件系统

ATA PIO 驱动 + FAT16 只读解析，ls / cat / diskinfo 命令操作磁盘

VGA 贪吃蛇

Mode 13h 像素渲染 + Ring 3 用户态游戏，系统调用读取输入，完整游戏循环
